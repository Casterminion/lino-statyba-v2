# Lino Statyba

Next.js website for [Lino Statyba](https://linostatyba.lt/).

## Structure

| Path | Purpose |
|------|---------|
| `site/` | Next.js application (pages, components, content, media) |

## Quick start

From the repo root:

```bash
npm install --prefix site
npm run dev
```

Open **http://localhost:3000**.

## Deploy

See [DEPLOY.md](DEPLOY.md). Import this repo in Vercel from the root folder and set **Root Directory** to `site`.
